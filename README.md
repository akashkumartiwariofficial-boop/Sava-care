# 🌸 SevaCare (सेवाकेयर) — Faith-Aligned Elder Care Platform 

**SevaCare** is a modern, responsive web application crafted to connect families with verified, compassionate caregivers and companions tailored to their cultural, religious, and dietary values across India.

---

## ✨ Key Features

- ☸️ **Faith & Culture Alignment**: Custom filter and caregiver matching based on religion (Hindu, Muslim, Sikh, Christian, Jain, Buddhist) and dietary preferences (Satvik, Pure Veg, Halal, Jain Food).
- 📍 **Pan-India Location Support**: Dynamic city, state, and pincode-based caregiver matching.
- 📦 **Tailored Seva Packages**: Transparent care packages ranging from ₹30,000 to ₹2,00,000/month (Day Companionship, 24x7 Live-in Seva, Medical & Dementia Care).
- 💳 **Integrated Digital Payments**: 
  - Real-time UPI QR Code Generator & Scanner simulation
  - Support for Google Pay, PhonePe, Paytm, BHIM UPI, Cards & Postpaid
  - Automated PDF receipts with GSTIN invoicing and WhatsApp sharing.
- 🚨 **Emergency SOS & Care Call**: Instant 1-click emergency alert system for elders.
- 🌐 **Bilingual Interface**: Seamless Hindi (हिंदी) and English toggle.
- 🛡️ **Verified Caregivers**: Comprehensive profile cards with ratings, verified badges, faith experience, and patient reviews.

---

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS
- **Animations & UI**: Framer Motion (`motion/react`), Lucide React Icons
- **Deployment**: Google Cloud Run / Static SPA

---

## 🚀 Getting Started

# Clone the repository
git clone https://github.com/your-username/sevacare.git

# Navigate to project directory
cd sevacare

# Install dependencies
npm install

# Run development server
npm run dev
